Termos editoriais — destaque/prioridade

⚡ Adição em lote (auto-detecta o feed)

Cole abaixo uma URL por linha (ou domínio simples como folha1.com.br). O sistema tenta os sufixos de feed comuns, vasculha o HTML por <link rel="alternate">, e se nada funcionar usa Google News como fallback. Cada URL leva 1-10 segundos para validar.
